01 / SNIPPETS

상용구 · 코드 스니펫 · 핫스트링

자주 쓰는 문구, 답변, 코드, 날짜 형식을 저장하고 단축키 한 번에 붙여넣기.
즐겨찾기(★)는 Ctrl + ; 미니팝업에서 바로 호출됩니다.

★ 안녕하세요, 6PM Assistant…AltF1

02 / SHORTCUTS

사이트 · 파일 · 폴더 바로가기

자주 가는 사이트와 폴더, 파일을 등록하고 단축키 한 번으로 열기.
사이트는 저장한 아이디·비밀번호를 함께 복사해 줍니다.

07

대시보드 진입
Ctrl+Alt+H

상용구 / 코드 스니펫

일반 텍스트, 코드, 제목 생성, 핫스트링 네 가지 카테고리로 정리. 즐겨찾기는 Ctrl + ; 미니팝업에서 바로 호출됩니다.

미니팝업
Ctrl+;

사이트·파일·폴더 바로가기

자주 가는 사이트, 폴더, 파일을 등록해 단축키로 호출합니다. 사이트는 저장한 ID/PW를 함께 복사해 줘서 로그인까지 끊김 없이.

컨닝페이퍼

자주 보는 KPI, 단축키표, 조직도 같은 이미지를 저장하고 필요할 때 화면 위로 띄워 참고합니다.

이미지 띄우기
Ctrl+Alt+F1

계산기

수식과 날짜를 계산해 결과를 클립보드에 바로 복사합니다. 계산 내역도 함께 보관됩니다.

계산기 호출
Ctrl+Alt+C

매크로 — 녹화 & 재생

마우스와 키보드 동작을 녹화하고 그대로 반복 재생합니다. 편집 화면에서 직접 수정도 가능해요.

녹화 시작 / 정지
Ctrl+Alt+R

클립보드 히스토리

복사했던 텍스트와 이미지를 자동으로 보관합니다. Ctrl을 두 번 누르면 미니팝업으로 바로 확인하고 골라서 붙여넣기.

미니팝업
Ctrl×2

텍스트 변환

URL 인코딩/디코딩, UTM 파라미터, 줄바꿈·따옴표 정돈까지 자주 쓰는 텍스트 처리를 한 번에.

변환 호출
Ctrl+Alt+T

빠른 메모 · 스티커

Alt을 두 번 누르면 메모/일정을 즉시 등록. 스티커 버튼을 누르면 바탕화면에 띄워 두고 볼 수 있어요.

빠른 메모
Alt×2
